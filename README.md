## What is HAKA?

A Filipino digital media and innovation brand connecting:
- **Youth** (Gen Z, students, young professionals)
- **Business** (Entrepreneurs, startups, SMEs)
- **Technology** (Professionals, tech enthusiasts)
- **AI** (All levels — from beginners to practitioners)

## Quick Start 🚀

### Run the AI Agent

```bash
# Install requirements (if needed)
pip install -r requirements.txt

# Run HAKA agent
python agents/content_creator/haka_agent.py
```

## Features ✨

### 🎯 Smart Content Planning
- Editorial mix: Tech 30%, AI 30%, Business 25%, Youth 15%
- Phase-aware suggestions (awareness → authority → community)
- Audience-specific hooks and tone matching

### 🇵🇭 Taglish Copywriting
- Natural Taglish flow (not robotic translations)
- Platform-appropriate style
- Strong hooks within first 3 seconds/lines

### 📱 Multi-Platform Support
- YouTube (long-form)
- TikTok/Reels (short-form)
- Instagram (visual storytelling)
- LinkedIn (professional insights)

### 📈 Growth Roadmap
1. **Phase 1** — Build Awareness ✅ (Current)
2. **Phase 2** — Build Authority
3. **Phase 3** — Build Community
4. **Phase 4** — Business Ventures
